An entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one line to `/output/entry.txt`: the museum label a museum in the year 3000 puts beside an ordinary object from today — a self-checkout terminal, misread by a deadpan curator from the future.

## Entry

> Self-checkout terminal, c. 2025. A machine that made shoppers do the cashier's job, then accused them of theft.

## Run

```sh
python3 main.py
```

The program is deterministic: it always writes the same single line, 111 characters, well within the 200-character limit.
